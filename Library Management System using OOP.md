# Library Management System using OOP

**Title:** Library Management System using OOP

**Description:**

This project demonstrates Object-Oriented Programming by implementing an interactive Library Management System in Python.

The system allows a library to manage books and patrons and perform basic library operations through a menu-driven interface.

## Features

- Add Books
- Register Patrons
- Borrow Books
- Return Books
- Display All Books
- Display All Patrons
- Display Borrowed Books
- Input validation
- Menu-driven interface

## Classes

### Book
Stores:
- Book ID
- Book title
- Author
- Availability status

### Patron
Stores:
- Patron ID
- Patron name
- List of borrowed books

### Library
Manages:
- Books
- Patrons
- Adding books
- Registering patrons
- Borrowing books
- Returning books
- Displaying records
